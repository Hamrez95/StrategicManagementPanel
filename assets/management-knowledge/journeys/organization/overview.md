# Organization journey

Product synthesis v0.1: triage → baseline → context and constraint diagnosis → choices → resource allocation → execution → review. The JSON is canonical. It does not claim a scientifically proven order.

Unlike a startup discovery path, an operating company may import existing statements and decisions. Only modules relevant to the immediate question open. An enterprise may run startup discovery for a new venture. Cash triage can interrupt all paths. Detailed HR, supply-chain and transformation modules remain research gaps.
