# مرجع کاراکتر آکادمی

این دو PNG اصلی از چت اشتراکی مالک بازیابی شدند؛ فایل مرجع با تصویر تولیدشدهٔ قدیمیِ موفرفری تفاوت دارد و همان نسخهٔ کت‌وشلوار مشکی است که مالک در گفت‌وگو پسندیده است.

- `approved-executive.png`: تصویر پایهٔ تأییدشده.
- `approved-six-poses.png`: کالکشن تأییدشده؛ بالا از چپ خوشامد، فکر، راهنمایی؛ پایین از چپ تأیید، تلاش دوباره، جشن.

منبع: https://chatgpt.com/share/6ad463d6-4364-83ed-947e-3d62eee4eb87

PNGها عین فایل دانلودشده‌اند؛ لینک موقت امضاشده و دادهٔ ورود در مخزن ذخیره نشده است. کانال alpha هر دو فایل بررسی شد. تأیید مالک به معنی ادعای حقوق انحصاری یا مجوز تجاری اشخاص ثالث نیست.

منبع ماندگار فایل‌های رابط در `public/assets/academy/mascot/` است؛ ساخت پروژه آن را به `apps/web/public/assets/academy/mascot/` و سپس dist کپی می‌کند. فایل‌ها: شش SVG مستقل که نسخه WebP همین اطلس را درون خود دارند؛ هیچ وابستگی تصویری خارجی ندارند. ماسک‌های هر قاب، بخش‌های شخصیت مجاور را حذف می‌کنند؛ خود پیکسل‌های شخصیت بازطراحی نشده‌اند. atlas.webp و base.webp نیز از PNGهای اصلی با حفظ alpha فشرده شده‌اند. SVGها ظرف نمایش تصویر raster هستند، نه طراحی وکتوری تازه.

برای جداکردن حالت‌ها imagegen نیز امتحان شد؛ فقط thinking و retry خروجی دادند و درخواست مستقل welcome با moderation_blocked در مرحله output رد شد (request ID: 32a5c74c-f11f-46d3-bd3e-9f386671aca1). این خروجی‌های بازطراحی‌شده در UI استفاده نشده‌اند. نسخه نهایی از همان فایل اصلی بازیابی‌شده استفاده می‌کند.
