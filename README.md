# رویش — پنل مدیریت استراتژیک

پروتوتایپ تعاملی فارسی و راست‌به‌چپ برای مدیر استراتژی و بنیان‌گذار استارتاپ؛ با یک شرکت کاملاً فرضی، داده نمونه، فونت محلی وزیرمتن و مسیر آموزشی از شناخت کسب‌وکار تا اجرای استراتژی.

## تجربه کاربری

- مسیر شش‌مرحله‌ای: تعریف مسئله، شناخت محیط، ارزیابی داخلی، انتخاب، اجرا و بازبینی.
- ۱۸ بخش کاری: نمای مدیریتی، مسیر شروع، پروفایل شرکت، محیط، صنعت، تحلیل داخلی، ماتریس‌ها، SWOT/TOWS، اتاق تصمیم، مالی، سناریو، اجرای ۹۰روزه، کارت امتیازی، ریسک، دفتر تصمیم، گزارش، آموزش و تنظیمات.
- ۹ ابزار ماتریسی: EFE، IFE، CPM، SPACE، BCG، IE، GE، Ansoff و Grand Strategy؛ همچنین QSPM و VRIO در بخش‌های مربوط.
- نمودار روند و هدف، رادار پنج نیرو، حباب BCG، بردار SPACE، نقشه استراتژی، نقشه حرارتی ریسک و برد اجرای برنامه.
- ویرایش وزن‌ها و امتیازها، محاسبه زنده نسبت‌های مالی و سناریو، ایجاد و ویرایش تصمیم‌ها، فرضیه‌ها، ریسک‌ها، اهداف و اقدامات.
- راهنمای زمینه‌ای با حرکت نشانگر یا فوکوس روی آیکن اطلاعات؛ توضیح کامل، فرمول، مثال، تفسیر، محدودیت و منبع با کلیک یا لمس.
- ذخیره مرورگر، پشتیبان JSON با اعتبارسنجی، چاپ گزارش/PDF، جست‌وجوی سراسری و حالت راهنمای سبک برای استارتاپ.

## اجرا و بررسی

Node.js 22 یا جدیدتر. وابستگی اجرایی یا نیاز به دریافت کتابخانه از CDN وجود ندارد.

### اجرای محلی در ویندوز

در PowerShell، از ریشه ریپو اجرا کنید:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\run-local.ps1
```

رانر به‌طور پیش‌فرض `main` و `HEAD` فعلی را در دو پوشه موقت و به‌ترتیب روی `http://localhost:4173` و `http://localhost:4174` اجرا می‌کند. `HEAD` یعنی کامیت فعلی؛ اگر هر دو ref به یک کامیت اشاره کنند، دو نسخه یکسان خواهید دید. برای اجرای یک شاخه یا کامیت خاص:

```powershell
.\run-local.ps1 -Refs main
.\run-local.ps1 -Refs main, feature/my-change
```

با `Ctrl+C` سرورها بسته می‌شوند و worktreeهای موقت پاک می‌شوند. اجرای پروژه روی شاخه کاری فعلی اثری ندارد. برای باز نکردن خودکار مرورگر از `-NoBrowser` استفاده کنید.

```sh
npm run check
npm test
npm run build
```

خروجی در `dist/` ساخته می‌شود و باید با یک میزبان فایل استاتیک ارائه شود؛ بازکردن مستقیم فایل با `file://` مناسب ماژول‌ها و Service Worker نیست. برای نصب PWA به HTTPS یا localhost و مرورگر پشتیبان نیاز است.

## تنظیمات Vercel

ریپو را در Vercel Import کنید:

| گزینه | مقدار |
| --- | --- |
| Framework Preset | Other |
| Root Directory | ریشه ریپو |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm install` |
| Environment Variables | لازم نیست |

`vercel.json` همین تنظیمات و هدرهای امنیتی را تعریف می‌کند. مسیرها hash-based هستند؛ همه صفحات از نقطه ورود استاتیک استفاده می‌کنند. اولین انتشار از اتصال موجود به Vercel به علت نداشتن مجوز ایجاد پروژه متوقف شد؛ هنوز URL انتشار تأییدشده‌ای ثبت نشده است.

## حدود نسخه نمونه

این نسخه نرم‌افزار سازمانی عملیاتی نیست: ورود و نقش‌های واقعی، بک‌اند، چندسازمانی، همگام‌سازی ابری، اعلان زمان‌بندی‌شده، اتصال ERP و موتور توصیه هوش مصنوعی ندارد. همه اطلاعات در همین مرورگر و همین دامنه ذخیره می‌شوند؛ پاک‌کردن داده مرورگر یا تغییر دامنه، اطلاعات را منتقل نمی‌کند. از داده حساس واقعی استفاده نکنید و پشتیبان بگیرید.

مدل‌های تحلیلی ابزار تصمیم‌سازی‌اند، نه تضمین رشد یا نسخه واحد برای همه صنایع. داده، واحد، دوره، فرضیات و محدودیت‌های هر مدل در رابط نمایش داده می‌شوند. برخی نمودارهای آموزشی، از جمله GE، نمایش کارگاهی ساده‌شده‌اند و این موضوع در همان صفحه تصریح شده است.

## ساختار و مستندات

- `src/app.js`: صفحات، فرم‌ها، رویدادها و ذخیره‌سازی.
- `src/data.js`: شرکت نمونه، محتوا، درس‌ها و منابع.
- `src/calculations.js`: محاسبات مستقل از رابط.
- `src/charts.js` و `src/styles.css`: نمودارها و طراحی واکنش‌گرا.
- `public/`: نقطه ورود، فونت، آیکن‌ها، manifest و Service Worker.
- [منطق طراحی](docs/DESIGN.md)، [روش‌شناسی و منابع](docs/METHODOLOGY.md)، [نتایج و محدودیت‌های تست](docs/VERIFICATION.md).

طراحی از وضوح ناوبری و آرامش بصری Buffer الهام گرفته، بدون کپی هویت آن. فونت [Vazirmatn](https://github.com/rastikerdar/vazirmatn) با مجوز SIL OFL در `public/assets/OFL.txt` نگهداری می‌شود.
