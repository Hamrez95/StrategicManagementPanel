## Shared architecture and exact UI contracts

- `/preview/w/:spaceId/strategy` is the directory: six navigational phases, 21 domain filters, search/type filter/pagination and explicit matrix/marketing shortcuts. Phases are navigation, not a scientific Journey or forced maturity sequence. Main navigation stays at five destinations.
- `/tool/:toolId` covers original local tools and authored `planningDesigns` flows. Foundation starts from `business` or directory; vision/mission are not silently prefilled from a registration objective. `planningDesigns.ts` owns stable field/step IDs, questions, help and statement/canvas/comparison/review layouts.
- `/research/:recordId` uses exact catalog IDs. `design-research.json` is a reproducible **design projection**, generated by `build-design-research.mjs`. It is not a runtime-approved knowledge release, API schema or permission source. Do not edit it manually or send its generic draft map straight to the server. Preserve canonical source path/ID and source-alias normalization.
- `ResearchWorkbench` provides contextual setup, input cards, help/method sources, a user-written draft and typed result layout. Existing `GuidedFlow` handles local drafts and transitions. `MetricDraftField` defines the numeric, currency, date, text and period-series presentation. BMC's nine blocks and evidence card are a product-authored presentation adapter.
- Local text namespaces are compatibility fixtures only: `<toolId>:<fieldId>` and `research:<recordId>:<step/inputId>` with UI progress/observation-state metadata. The API maps these to reviewed canonical entities, never one unbounded answer JSON endpoint. Per-input observation state remains independent of numeric value; zero is not unknown.
- No new advanced calculator or automatic diagnosis is implemented by these pages. Scope, numeric preview, scientific applicability, method approval, persistent run and final human decision are distinct states. Formula text is never evaluated dynamically. No invented matrix position, score, success threshold or completion claim.
