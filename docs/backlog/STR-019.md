## زمینه، اثر و شواهد

محصول استراتینو برای مدیر چند پروژه و مدیر/بنیان‌گذار فارسی‌زبان است. خط پایه فعلی پروتوتایپ localStorage است؛ auth، tenant isolation، paid billing و بایت فایل واقعی ندارد. قابلیت‌های محاسبات، آموزش و زبان موجود باید طبق جدول parity حفظ شوند.
این تسک یک بخش محدود از مسیر تحلیل→تصمیم→اجرا→مدارک است؛ scope زیر نتیجه قابل تحویل را تعریف می‌کند. ریسک‌های SaaS فرض امنیت فعلی نیستند؛ شرط ساخت نسخه جدیدند. اطمینان درباره خط پایه زیاد و درباره قیمت/تقاضای بازار پایین است.

## پیشرفت توسعه

- عامل SWOT با دسته، شاهد اجباری، مسئول، اولویت ۱ تا ۵ و revision در سطح Workspace ذخیره می‌شود.
- گزینه TOWS اقدام، منطق، فرضیه، محدودیت و پیوند صریح به عوامل همان Workspace دارد؛ ساخت فقط با جفت دسته معتبر ممکن است.
- ویرایش معنایی عامل گزینه‌های مرتبط را نیازمند بازبینی می‌کند. حذف عامل ابتدا وابستگی را گزارش می‌دهد؛ پس از تأیید، گزینه را نگه می‌دارد، پیوند را حذف و گزینه را برای بازبینی علامت‌گذاری می‌کند.
- تست API و سناریوی مرورگر شامل مجوز، جداسازی Workspace، revision، جفت‌سازی، حذف وابسته و ترمیم گزینه نوشته شده‌اند. اجرا، migration واقعی، screenshot و بررسی صفحه‌کلید/تم/اندازه صفحه هنوز انجام نشده و issue باز می‌ماند.
- Graphify پس از تغییر کد در حالت AST محلی به ۱۸۹۶ node و ۳۹۹۰ edge به‌روز شد؛ query محدود مصرف‌کنندگان `SwotPage`, `strategy/api.ts`, `strategy/services.py`, مدل پیوند و تست API را نشان داد. برچسب‌گذاری LLM اجرا نشد.
- rollback کد با revert انجام می‌شود. migration برگشت‌پذیر است اما حذف جدول‌های تازه داده SWOT/TOWS را پاک می‌کند؛ پس از هر ذخیره واقعی، قبل از rollback باید از پایگاه‌داده نسخه پشتیبان گرفت.
