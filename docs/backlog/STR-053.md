# STR-053 — گیت یکپارچگی دانش و آزمون رگرسیون منفی

Priority: **P0** | Epic: **MOS-KNOWLEDGE** | Status: planned. Dependencies: STR-005.

## Context / Problem

Research validator passes but skips some documents, duplicate JSON keys, auxiliary IDs and production promotion boundaries.

## Goal / User value

Read-only traversal of every JSON/YAML/frontmatter with stable hash inventory; independently reconstruct IDs and typed references. The manager reuses trustworthy business information and reaches a defensible next action with less repeated input.

## Scope / Functional requirements

- Read-only traversal of every JSON/YAML/frontmatter with stable hash inventory; independently reconstruct IDs and typed references.
- Validate source aliases, question/evidence links, metric prerequisites, startup reachability; distinguish legal transition returns from forbidden prerequisite cycles.
- Add isolated CI gate and mutation tests; report research limitations without claiming scientific certification.

## Non-goals

No new hosting, paid services, generic workflow DSL, graph database, arbitrary health score or opaque AI decision logic. Preserve legacy tools; no unrelated domain expansion. No decorative UI or invented production endpoint is required.

## Domain impact / Data requirements

Follow the ownership and contracts in [ARCHITECTURE](../management-os/ARCHITECTURE.md). Public KB only; never ingest company observations into public research. Any persistence/schema change needs an explicit version and compatibility/rollback plan before apply.

## Knowledge-base dependencies

- `assets/management-knowledge/validation/validate.mjs`
- `assets/management-knowledge/validation/record-contracts.json`
- `assets/management-knowledge/catalog.json`

## UX requirements / Accessibility

Return actionable bounded errors with affected IDs/fields; do not leak evidence or require managers to understand engine internals. When surfaced in UI, unknown/invalid/stale states need text and keyboard-accessible explanation, not color alone.

## AI involvement / Deterministic logic

AI has no authority in this task. Reviewed IDs, versions, permissions, derivation, formulas, gates and completion are deterministic; source prose is never eval-executed. Any later AI wording is a reviewable draft outside this scope.

## Security / Privacy

Knowledge files are public content only; reject path traversal/symlink escape, unknown shapes and unapproved runtime promotion. No external paid extraction.

## Acceptance criteria

- [ ] Given a removed metric still referenced by a rule, validation fails and names the file/ID.
- [ ] Given duplicate JSON keys, unknown schema or unreachable startup node, CI fails; intentional startup return edges pass.
- [ ] Given normal KB, audit leaves every KB byte unchanged and reports all eight recommendation chains.
