## این نمونه کجای هسته می‌نشیند؟

این بستهٔ آزمایشی پلی میان C01-M2 و C01-M3 و C01-M4 است. شناسهٔ پژوهشی آن `PILOT-C01-01` است و ماژول پنجم جدید یا محصول فروشی جدا نیست. مخاطب، فرد بدون سابقهٔ حسابداری است؛ درصد، ضرب و تفریق کافی است. گذراندن درس قبلی شرط دسترسی نیست.

## منابع و مرز استفاده

برای جایگاه مفاهیم در آموزش دانشگاهی: [تقویم حسابداری MIT، بهار ۲۰۰۴](https://ocw.mit.edu/courses/15-501-introduction-to-financial-and-managerial-accounting-spring-2004/pages/calendar/)، جلسه‌های ۳ و ۴، ۹ و ۱۰ و ۲۲ تا ۲۴. سطح این درس کارشناسی است. سیلابس، شاهد آموزش این موضوع‌هاست؛ استاندارد جاری حسابداری ایران نیست.

محل مطالعهٔ تکمیلی: بخش‌های ۲٫۱ حسابداری مالی، ۳٫۱ و ۷٫۲ حسابداری مدیریت OpenStax که در [طرح C01](../curriculum/c01.md) پیوند دارند. این‌ها مرجع مطالعه‌اند و اجازهٔ کپی تجاری یا ورود متن کتاب به محصول AI از آن‌ها استنباط نمی‌شود. مثال و اعداد این نمونه مستقل ساخته شده‌اند. پیش از انتشار، نگاشت ادعابه‌ادعا و مرور متخصص حسابداری باقی است.

بخش AI یک سناریوی فرضی هزینه است. مطالعهٔ R06 دربارهٔ خدمت پشتیبانی، شاهد کاهش هزینهٔ شرکت فرضی ما نیست.
