## حد ادعای این مجموعه

بررسی یک صفحهٔ سرفصل، به معنی خواندن کتاب یا داوری علمی مقاله نیست. در هر نگاشت، محل شاهد و عمق مرور جدا ثبت می‌شود. طرح تفصیلی، متن کامل دوره نیست. منابع قدیمی برای مفاهیم بنیادی می‌توانند مفید باشند؛ سال آرشیو آن‌ها حفظ می‌شود. منابع ۲۰۲۶ تنها به دلیل تازه‌بودن برگزیده نمی‌شوند.

فایل‌های `courses/core/` نقشهٔ اکتشافی قبلی را حفظ می‌کنند. طرح این گذر در `core-review/curriculum/` است. شناسه‌های C01 تا C10 و چهار ماژول قبلی حفظ شده‌اند تا پیوندها نشکنند. ماژول نمونه میان چند ماژول حسابداری پل می‌زند و ماژول پنجمِ تازه‌ای به کاتالوگ اضافه نمی‌کند.
