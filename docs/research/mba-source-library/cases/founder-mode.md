# مدیریت بنیان‌گذار: یک روایت حرفه‌ای برای نقد

زمینه: اکوسیستم استارتاپ؛ تفسیر شخصی و حرفه‌ای.

وضعیت: `professional_opinion_for_critical_discussion`. درس‌های مرتبط: C05، C07، S01، S04، S06.

## دامنهٔ واقعیت ثبت‌شده

نویسنده در یادداشت خود دربارهٔ سبک مدیریت بنیان‌گذار بحث می‌کند.

منابع و پیوندهای اصلی: [P05](../source-catalog.md#منبع-p05).

## پرسش پیشنهادی برای طراحی آموزش

کدام بخش روایت به زمینهٔ شرکت وابسته است و برای پذیرش ادعا به چه شاهدی نیاز داریم؟

این پرسش، پیشنهاد تدوین‌کننده است. هنوز پاسخ درس‌نامه یا نتیجهٔ اثبات‌شدهٔ شرکت نیست.

## حدود شواهد

یادداشت، مقایسهٔ تجربی سبک‌های مدیریت نیست؛ نتیجهٔ عمومی یا تأیید سبک خاص از آن استنباط نشود.

## شاهد بعدی

پژوهش مستقل دربارهٔ تفویض اختیار، ساختار و عملکرد بنیان‌گذاران به آن پیوند بخورد.

متن، تصویر و کیس اختصاصی ناشر بازنشر نشده است. برای روایت نهایی، ترتیب زمانی و نقل‌قول‌ها باید از نسخهٔ اصلی کنترل شوند.
