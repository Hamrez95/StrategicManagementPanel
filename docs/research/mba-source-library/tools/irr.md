# نرخ بازده داخلی IRR

وضعیت پژوهش: `formula_and_software_guide_found`. درس‌های مرتبط: C03، S02، E04.

## تصمیم و ورودی

کدام نرخ NPV جریان‌ها را صفر می‌کند؟

ورودی‌ها: جریان‌های نقد با قرارداد زمانی مشخص.

## مراحل و خروجی

ریشهٔ معادلهٔ NPV=۰ را پیدا کنید؛ با NPV و نرخ لازم مقایسه کنید.

رابطهٔ پیشنهادی: `IRR: r where NPV(r)=0`؛ برای زمان نامنظم از قرارداد XIRR استفاده شود.

## محدودیت و بررسی AI

ممکن است ریشهٔ متعدد یا هیچ ریشه‌ای وجود داشته باشد؛ رتبه‌بندی پروژه‌ها همیشه سازگار نیست.

برای کاربرد AI، ورودی، فرض، محاسبه و خروجی باید قابل بازبینی باشند. جایگزینی دادهٔ واقعی با عدد تولیدشده مجاز نیست. شواهد موضوعی AI در صفحهٔ درس‌های مرتبط آمده است.
