# راهنمای فیلدها و وضعیت‌ها

فایل source-register.json مرجع مرکزی است. CSV برای مرور جدولی از همان داده ساخته شده است. شناسهٔ منبع ثابت می‌ماند. عنوان و ویرایش متفاوت کتاب دو اثر یا نسخهٔ جدا محسوب می‌شوند؛ خبر و پست دربارهٔ یک مقاله، مطالعهٔ علمی مستقل از آن نیستند.

| فیلد | معنا |
|---|---|
| id | شناسهٔ یکتای رکورد |
| title / verified_title | عنوان نمایشی / عنوان تطبیق‌شده با Crossref در صورت موفقیت |
| authors / editors / corporate_author | نویسندگان، ویراستاران یا مؤلف سازمانی؛ خالی یعنی بازیابی نشده |
| year / edition | سال اثر یا شمارهٔ ثبت‌شده و نسخه؛ با تاریخ بررسی یکی نیست |
| published_online / published_print | تاریخ آنلاین و چاپی در صورت وجود در فراداده |
| last_checked | تاریخ بررسی این اجرا |
| course_ids / source_topics | پیوند به درس‌ها و موضوع‌های پیشنهادی خودمان |
| academic_role / adoption_evidence | نقش منبع و شاهد واقعی انتساب به کلاس؛ ارتباط موضوعی جای انتساب نیست |
| doi / isbn | شناسهٔ اثر؛ نبود مقدار به معنی نبود اثر نیست |
| access_check | نتیجهٔ دریافت مستقیم، کد HTTP و وضعیت محتوا |
| web_page_opened | ثبت اولیهٔ مشاهدهٔ صفحه در ابزار وب؛ معیار بررسی متن کامل نیست |
| crossref_check | نتیجهٔ تطبیق فراداده؛ matched، failed یا اختلاف عنوان |
| full_text_review_status / content_review_status | حدود خواندن محتوا؛ این فاز بررسی کامل همهٔ متون نیست |
| eligible_for_teaching | کاندیدبودن برای بررسی آموزشی؛ تأیید علمی نهایی یا مجوز انتشار نیست |
| license / reuse_status | مجوز مشاهده‌شده و وضعیت حقوق استفاده از متن، فایل یا نمودار |
| metadata_gaps | فیلدهای ناقص یا مجوز نامشخص |

در جدول انتساب، counts_as_verified_course_assignment برای خواندنیِ واقعاً دیده‌شده در فهرست کلاس است. counts_as_MBA_assignment فقط با تأیید برنامهٔ MBA درست می‌شود؛ Graduate به‌تنهایی این تأیید نیست. انتخابی‌های نمونهٔ سال‌های قبل نیز رفرنس کلاس جاری ۲۰۲۶ محسوب نمی‌شوند.

دسته‌های U اسناد برنامه و دسترسی‌اند. دستهٔ B کتاب‌ها، O هندبوک‌های OUP، M سیلابس و مواد دانشگاهی، R پژوهش و چارچوب مرتبط با AI، H آثار تاریخی، T منابع ابزار، K اسناد و مطالعات شرکت و P روایت یا گفت‌وگوی حرفه‌ای است. X هشدار یا منبع کنارگذاشته‌شده را ثبت می‌کند. این حروف رتبهٔ کیفیت نیستند.
