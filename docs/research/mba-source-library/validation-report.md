# نتیجهٔ کنترل داده‌های پژوهش

در تاریخ ۱۸ اکتبر ۲۰۲۶، یکتایی شناسه‌های منابع و DOIها، ارجاع موضوع‌ها و ابزارها و کیس‌ها، وجود ۲۲ مسیر و ۸۸ موضوع و پیوندهای محلی فایل‌های Markdown کنترل شد. همهٔ این کنترل‌ها گذشتند.

فرادادهٔ DOIهای تطبیق‌شده از Crossref و وضعیت دریافت مستقیم از ابزار HTTP جدا ثبت شده است. خطاهای ۴۰۳، محدودیت نرخ، صفحهٔ کم‌محتوا و منابع نیازمند بررسی متن به‌عنوان محدودیت باقی مانده‌اند. این کنترل، تأیید علمی مقاله‌ها یا تضمین همیشگی پیوندهای وب نیست.

کد اپ تغییر نکرده است. تست و build اپ برای این تغییر مستنداتی اجرا نشد. وضعیت انتشار Git در گزارش نهایی گفتگو اعلام می‌شود؛ فایل پژوهش، موفقیت push را پیشاپیش ادعا نمی‌کند.

کنترل نهایی پس از ویرایش فارسی نیز اجرا شد: ۷۷ فایل Markdown، پیوندهای محلی و لنگرهای منابع بررسی شدند. پیوند یا لنگر خراب و خطای گزارش‌شدهٔ نگارشی باقی نماند. فرمول‌ها، شناسه‌ها و مقصد پیوندها هنگام ویرایش محافظت شدند.
