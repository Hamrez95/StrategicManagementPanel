# Academy path visual refinement

The course heading now uses original SVG artwork selected by course ID. All 44 courses have an explicit primary motif, secondary motif and palette mapping: navigation and capability for strategy, ledgers and charts for finance, people for leadership, workflows for operations, networks for AI, and related combinations for specialist courses. No teaching data or answer keys changed.

The canvas and central Vazir typography remain unchanged. Course panels use the existing paper surface with restrained ocean (`#248bb8`), violet (`#8764c7`), copper (`#b87938`), berry (`#b25e86`) or teal (`#278d85`) artwork. Stage colour remains on the edge, stage marker and lesson discs instead of filling the whole header. Text stays right-aligned; decorative artwork sits beside it and shrinks independently on mobile.

Lesson discs breathe on a six-second cycle, with a slightly quicker halo on the suggested next lesson and staggered phases. Completed lessons use a gold surface, check mark, warm halo and slow highlight. Stage/final review completions get a matching gold accent. Titles do not move. System and account reduced-motion preferences disable the animations.

The ambiguous disabled bookmark action is now “ذخیره برای بعد”. Guests get a working sign-in link with a return destination. Signed-in learners can save/remove a lesson, see the save status and find it in Review. Guest practice completion is calculated from cards actually viewed and server-checked answers; it is temporary and never posted as authoritative account progress. Refocusing a guest tab preserves this temporary progress.

Representative browser checks covered strategy, finance and AI headings, desktop/mobile overflow, light/dark automated WCAG checks, actual guest lesson completion and its gold disc, sign-in routing, and account save/reload/review/removal. Screenshots here are real UI captures. Original SVGs replace the repetitive green banner without adding large raster downloads.
