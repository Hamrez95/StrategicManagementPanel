## اجرای محلی

`npm ci` سپس `npm run dev` و بازکردن `http://127.0.0.1:5173/academy`.
build عادی هم پیش‌نمایش تمرینی را در دسترس می‌گذارد. برای خاموش‌کردن آن، build را با `VITE_ACADEMY_PREVIEW=false` اجرا کن؛ `npm run test:academy:disabled` همین حالت را جداگانه می‌سازد و بررسی می‌کند. `npm run build:academy` میان‌بر اجرای پیش‌نمایش است و به‌تنهایی مجوز deploy نیست.
