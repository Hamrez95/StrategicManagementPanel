## اجرای محلی

`npm ci` سپس `npm run dev:academy` و بازکردن `http://127.0.0.1:5173/academy`.
فرمان استاندارد `npm run dev` بخش آزمایشی را فعال نمی‌کند. `npm run build:academy` فقط خروجی build آزمایشی می‌سازد؛ مجوز deploy نیست. برای build عادی `npm run build` و `/academy` باید صفحه نبود مسیر باشد. آخرین build نوع خروجی dist را تعیین می‌کند؛ پیش از انتشار احتمالی حتماً build عادی و کنترل نبود مسیر.
