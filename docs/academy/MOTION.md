# موشن آکادمی — اجرای مرجع موبایل، ۱۸ اکتبر ۲۰۲۶

مرجع مشاهده و تصمیم طراحی در MOBILE_REFERENCE.md است. شش تصویرِ تأییدشده بازیابی و استفاده شده‌اند؛ موشنِ فعلی از نوع presentation با CSS transform/opacity است، نه rig تازهٔ صورت، لب‌خوانی یا انیمیشن اندام‌ها. این سند جای وضعیت تاریخیِ صفر تصویر را می‌گیرد.

هیچ timer درستی پاسخ، امکان ادامه یا بازشدن بخش بعد را تعیین نمی‌کند. همه حرکت‌ها محدودند. کاهش حرکتِ سیستم یا تنظیم شخصی، حرکت آواتار/قاب/ذرات/نوار پیشرفت را حذف می‌کند و اطلاعات و امکان ادامه حفظ می‌شوند. ذرات aria-hidden و pointer-events:none دارند.

دیالوگ خروج با focus trap، Escape و برگشت focus از primitive موجود ساخته شده است. درس و یادداشت فقط در همین تب ذخیره می‌شوند؛ خطای ذخیره آشکار است. در موبایل ناوبری پایین فقط بیرون درس دیده می‌شود و درس، نوار پیشرفت و اقدام پایین خودش را دارد.

شاهد واقعی: ۳۷ بررسی مرورگر و ۱۸ scoped axe، تم‌ها و عرض‌های مختلف، حرکت محدود و reduced-motion. ویدئوی کوتاه motion-preview.mp4 از قاب‌های واقعی مرورگر ساخته شده؛ نرخ نمونه‌برداری آن ۱۵ فریم بر ثانیه است و سنجش FPS عملکرد محصول نیست. zoom آزمون موجود، بزرگ‌کردن فونت ۲۰۰٪ است. این QA گواهی WCAG یا تأیید علمی محتوا نیست.
