# استراتینو — هویت محصول و سازگاری داده

نام فارسی استراتینو، لاتین Stratino؛ منبع اجرایی `src/brand.js`. title، نشان sidebar/report و نام JSON از هویت محصول استفاده می‌کنند؛ manifest و HTML نقطه ورود همین نام را دارند. نشان S با مسیر تصمیم و فلش برگشت به اقدام طراحی شده، با رنگ فعلی آبی و کنتراست روشن/تیره؛ نشان شرکت نمونه مستقل است.

شرکت نمونه تازه «آوند / Avand» است تا نام ابزار با کسب‌وکار نمونه مخلوط نشود. اسم ذخیره‌شده کاربر یا شرکت قدیمی بازنویسی نمی‌شود. `royesh-strategy-v1` و `royesh-preferences-v1` عمداً باقی می‌مانند؛ schema و نسخه JSON تغییری نکرده، پس داده قبلی مستقیم خوانده می‌شود و نیاز به migration تخریبی نیست. خروجی جدید نام stratino-strategy-backup.json دارد و import قدیمی همچنان همان schema را می‌پذیرد.

هیچ نام دامنه/مخزن در GitHub تغییر نکرده است. مستندات تاریخی و نام کلید ذخیره استثناهای برند قدیمی‌اند. در تور، مثال به «شرکت نمونه» اشاره می‌کند؛ نام ثابت برند در داده شخصی وارد نمی‌شود.

نقد طراحی: S مسیرگونه جای نمودار generic در نشان محصول نشست؛ رنگ جدید بی‌دلیل یا تزئین اضافه وارد داشبورد نشد. تایپوگرافی و layout خط پایه حفظ شدند؛ هویت کامل صفحه عمومی در پایه React تکمیل می‌شود.
