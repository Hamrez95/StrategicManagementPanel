# فهرست ساختار نسخهٔ یک

قاعدهٔ شمارش: دایره فقط درس‌نامه است؛ مرور مرحله و آزمون درس با نماد و عنوان جدا نمایش داده می‌شوند. تعداد درس‌نامه‌ها شامل این مرورها نیست.
این نسخه جایگزین عدد اولیهٔ ۱۲۰ طرح درس‌نامه برای نمایش مسیر محصول می‌شود؛ نقشهٔ پژوهشی قبلی حذف نمی‌شود. ۲۸ موضوع تخصصی قبلی به ۲۸ درس، در هفت گرایش، گسترش یافته‌اند. هر درس تخصصی سه مرحله دارد. این گسترش، تألیف کامل متن آن‌ها نیست.
