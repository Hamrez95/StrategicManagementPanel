# آماده‌سازی از صفر

وضعیت: طرح ساختار برای توسعه؛ متن کامل و بانک سؤال همهٔ درس‌ها هنوز نوشته نشده است. رنگ مرحله، موضوع مسیر را مشخص می‌کند و نشان قبولی نیست.

## درس P00؛ آماده‌سازی اختیاری

تعداد: ۲ مرحله و ۸ درس‌نامه. ورود مستقیم به هر درس‌نامهٔ داخل بسته مجاز است.

### مرحلهٔ ۱؛ زبان کسب‌وکار و عدد

رنگ: `green`؛ شناسه: `P00-ST01`.

| دایره | درس‌نامه |
|---|---|
| `P00-ST01-L01` | مشتری، ارزش و درآمد |
| `P00-ST01-L02` | درصد، نسبت و تغییر |
| `P00-ST01-L03` | مانده با جریان چه فرقی دارد؟ |
| `P00-ST01-L04` | خواندن جدول و نمودار ساده |


پس از این مرحله: مرور ۶ پرسشی. این مرور، دسترسی مرحلهٔ بعد را قفل نمی‌کند.

### مرحلهٔ ۲؛ روش مطالعه و شواهد

رنگ: `blue`؛ شناسه: `P00-ST02`.

| دایره | درس‌نامه |
|---|---|
| `P00-ST02-L01` | واقعیت، ادعا و فرض |
| `P00-ST02-L02` | تمرین را چطور حل کنیم؟ |
| `P00-ST02-L03` | منبع و تاریخ را چطور بخوانیم؟ |
| `P00-ST02-L04` | یادداشت و مرور فاصله‌دار |


پس از این مرحله: مرور ۶ پرسشی. این مرور، دسترسی مرحلهٔ بعد را قفل نمی‌کند.
