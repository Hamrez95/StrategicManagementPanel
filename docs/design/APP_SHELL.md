# طرح پوسته پنل

## طرح و بازبینی پیش از پیاده‌سازی

- رنگ: از توکن‌های محصول استفاده می‌شود: بوم `#f8fafc`، سطح `#ffffff`، جوهر `#172b4d`، کنش `#2459ed`، تأکید شواهد `#0f766e` و خط کنترل `#718198`. وضعیت فعال با یک نوار باریک و پس‌زمینه semantic مشخص می‌شود؛ رنگ تازه‌ای اضافه نمی‌شود.
- تایپ: Vazirmatn محلی با اندازه پایه ۱۶px؛ تیتر صفحه ۲۸–۳۲px و برچسب کمکی ۱۴px. نام ابزار و Workspace از متن واقعی می‌آیند.
- چیدمان: در دسکتاپ مسیرها در ستون ثابت سمت راست RTL قرار می‌گیرند و ناحیه محتوا با عرض خوانا کنار آن می‌ماند. در موبایل، همان مسیرها در گفت‌وگوی کشویی با focus trap و بازگشت focus نمایش داده می‌شوند.
- سازمان‌دهی: فهرست واقعی prototype به پنج مرحلهٔ شناخت، تحلیل، تصمیم، اجرا و مدارک نگاشت می‌شود؛ هر ابزار URL مستقل دارد. صفحهٔ حساب و صفحهٔ تنظیمات Workspace دو مسیر جدا هستند.
- داده: routeهای ابزار، نگاشت hash قدیمی را نگه می‌دارند. prototype فقط پس از انتخاب صریح کاربر باز می‌شود و هشدار می‌دهد اطلاعاتش محلی است و به Workspace سرور متصل نیست.

```text
دسکتاپ RTL
┌──────────────────────────────────────────────────────────────┐
│ استراتینو   [فضا: نام پروژه ▾]   [جستجو  /]   [حساب ▾]        │
├─────────────────┬────────────────────────────────────────────┤
│ شناخت           │ خانهٔ فضای کار / نام صفحه                 │
│  مسیر استراتژی  │                                            │
│  شناخت شرکت     │ تیتر روشن                                  │
│ تحلیل           │ یک توضیح کوتاه و اقدام واقعی              │
│ تصمیم           │                                            │
│ اجرا            │ محتوای صفحه در عرض خوانا                   │
│ مدارک           │                                            │
└─────────────────┴────────────────────────────────────────────┘

موبایل
┌──────────────────────────────┐
│ [منو] استراتینو [جستجو] [حساب]│
│ [فضا: نام پروژه ▾]            │
├──────────────────────────────┤
│ مسیر: شناخت / تحلیل / ...    │
│ تیتر صفحه                     │
│ محتوای صفحه                   │
└──────────────────────────────┘
```

گزینهٔ بررسی‌شده برای دسکتاپ، نوار آیکون باریک بود؛ کنار گذاشته شد چون نام‌های روشن ابزار برای مدیرانی که هر روز بین تحلیل، تصمیم و اجرا جابه‌جا می‌شوند از چند پیکتوگرام مبهم سریع‌تر است. طرح نهایی از یک ستون معنایی استفاده می‌کند، نه کارت‌های هم‌اندازه یا تزیینات تکراری. روی موبایل از Dialog موجود استفاده می‌شود تا بستن با Escape، مهار focus و بازگرداندن آن به دکمهٔ منو یکسان با بقیهٔ محصول باشد.

## قرارداد route

- هر ابزار یک شناسهٔ پایدار و `legacyHash` در route registry دارد.
- مسیر مستقل `/app/workspaces/:workspaceId/tools/:toolId` به صفحهٔ ابزار می‌رسد؛ `/overview`, `/settings`, `/account` مسیرهای جدا باقی می‌مانند.
- مسیرهای قدیمی زیر Workspace به registry نگاشت و با `replace` به URL مستقل می‌روند. hashهای عمومی prototype همچنان به نسخهٔ قدیمی می‌روند.
- صفحهٔ ابزار تا زمان اتصال داده در تسک‌های بعدی، فقط مرز و توضیح روشن نشان می‌دهد؛ بازکردن prototype یک انتخاب آگاهانه است و دادهٔ نمونه را با Workspace واقعی مخلوط نمی‌کند.

## بررسی نهایی طراحی

طرح با `docs/UX_STANDARD.md` سنجیده می‌شود: RTL/LTR و اعداد محلی، دو تم، نقاط ۳۶۰/۷۶۸/۱۲۸۰/۱۴۴۰، focus و keyboard، reduced-motion، بارگیری/خطا/خالی/موفقیت و نبود overflow. اجرای تصویری و آزمون مرورگر تا مرحلهٔ نهایی اعتبارسنجی باقی می‌ماند.
