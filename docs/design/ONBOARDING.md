# طرح ورود به فضای کار

## طرح و بازبینی پیش از پیاده‌سازی

- رنگ: همان توکن‌های semantic روشن/تیره محصول؛ جوهر `#172B4D`، بوم `#F8FAFC`، سطح `#FFFFFF`، خط `#DCE4EF`، کنش `#2459ED` و تأکید موفقیت `#0F766E`. رنگ تازه یا گرادیان برای ویزارد اضافه نمی‌شود.
- تایپ: Vazirmatn محلی؛ تیتر ۲۸–۳۲px، متن ۱۶px با line-height خوانا، نام و هدف پروژه با همان خانواده فونت.
- چیدمان: روی دسکتاپ فرم با عرض خوانا در یک ستون اصلی قرار می‌گیرد و یک مسیر باریک، سه گام واقعی «اطلاعات شما → نام پروژه → هدف پروژه» را نشان می‌دهد. روی موبایل مسیر به progress کوتاه بالای فرم تبدیل می‌شود؛ هیچ فرم دو ستونه‌ای فشرده نمی‌شود.
- رفتار: هر گام یک هدف دارد. اطلاعات شخصی و نام پروژه با دکمه ادامه روی سرور ذخیره می‌شوند تا بعد از refresh ادامه مسیر ممکن باشد. اطلاعات پروژه قابل ویرایش می‌ماند؛ صنعت، مرحله و هدف می‌توانند خالی بمانند و دکمه ردکردن روشن دارند. دمو فقط با انتخاب صریح باز می‌شود.

```text
دسکتاپ / RTL
[استراتینو]                                      [نمونه تعاملی]
┌─────────────────────────┬────────────────────────────────────┐
│ مسیر شما                │ اطلاعات اولیه پروژه                │
│ ۱  اطلاعات شما          │ این کسب‌وکار در چه زمینه‌ای است؟    │
│ ۲  نام پروژه            │ [صنعت]                              │
│ ۳  هدف پروژه            │ [مرحله فعلی]                        │
│                         │ [هدف یا مسئله اصلی]                 │
│                         │ [بازگشت] [ردکردن] [ذخیره و ادامه]   │
└─────────────────────────┴────────────────────────────────────┘

موبایل
[استراتینو] [گام ۳ از ۳]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
هدف پروژه
یک هدف برای شروع بنویسید؛ می‌توانید بعداً تغییرش دهید.
[متن هدف]
[بازگشت] [ردکردن] [ذخیره و ادامه]
```

بازبینی: صفحه سه کارت برابر، درصد تزئینی یا رنگ تازه می‌توانست شبیه ویزارد عمومی SaaS شود. طرح نهایی از مسیر واقعی مدیر استفاده می‌کند و نام شخص/پروژه‌ی ثبت‌شده را در پیشرفت نشان می‌دهد. فرم همیشه مرکز توجه می‌ماند؛ مسیر کناری فقط پاسخ می‌دهد «کجا هستم؟» و دمو را به‌عنوان انتخاب فرعی نگه می‌دارد.

## قاعده‌های پیاده‌سازی

- کاربر جدید: نام نمایشی → ساخت یک Workspace واقعی → اطلاعات اختیاری صنعت/مرحله/هدف. هر مرحله سروری ذخیره می‌شود و مرحله ناقص بعد از refresh از اطلاعات حساب و Workspace بازسازی می‌شود.
- کاربر عضو دعوتی که Workspace مالکیتی ندارد مستقیم به فهرست فضاهایش می‌رود؛ در آن مسیر Workspace تازه ساخته نمی‌شود.
- تکمیل مسیر در پروفایل پروژه ثبت می‌شود. وضعیت complete فقط راهنمای onboarding است و جایگزین مجوز Workspace نیست.
- حالت بارگیری، خطای شبکه با retry، خطای فیلد، تعارض revision و موفقیت از هم جدا هستند. دکمه‌های ادامه/ذخیره هنگام درخواست غیرفعال می‌شوند.
- RTL/LTR، تم روشن/تیره، focus کیبورد، reduced-motion و breakpointهای ۳۶۰/۷۶۸/۱۲۸۰/۱۴۴۰ در مرورگرهای نهایی بررسی می‌شوند؛ تصویر و نتیجه‌ی این بررسی تا پایان مرحله‌ی آزمون ادعا نمی‌شود.
