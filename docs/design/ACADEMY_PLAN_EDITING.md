# Academy catalog editing

`/internal/academy_plans` supports title, catalog visibility, original/sale price and duration edits. Amounts are explicitly **IRR (rials)**; specialty prices are per selected area. Empty amount/discount/duration means `null`, not zero. Coverage kind, plan code and currency cannot be changed through this form. Free samples cannot acquire a price. Checkout remains disabled until the existing payment launch requirements are met.

`GET/PATCH /api/v1/operator/academy_plans/{plan_id}/` requires active verified staff, approved OperatorAccess, the Academy plans section, a current session-bound MFA proof, and either the configured owner role or explicit `academy.change_academyplan`. Mutations additionally require CSRF and a change reason. Owners can delegate the edit permission in team administration. The capability is reported by operator status, not inferred from staff flags in the UI.

The canonical plan payload has a SHA-256 version. PATCH locks the plan and compares that version before writing; a stale editor receives `409 revision_conflict`. The form retains the draft and offers an explicit reload. A successful save updates the operator list and invalidates Academy plan and account subscription queries. Public plan/quote endpoints read the same AcademyPlan data. Historical orders and subscription snapshots are not rewritten. Repeating the current values creates no duplicate audit event.

Migration `operations.0007_academy_plan_audit` adds structured before/after snapshots to append-only operator events and extends both event-type database guards. Existing audit rows keep their meanings. Audit insertion and the catalog edit share one transaction. Roll back application code with this additive schema retained; do not remove audited price edits to force a schema downgrade. A database backup is required before applying the migration to an existing environment.

Validation: `modules.operations.test_academy_plans` covers permissions, MFA, CSRF, configured owner access, invalid values, conflicts, unchanged purchase snapshots, public propagation and rollback on audit failure. `scripts/verify-global-admin.mjs` covers Persian numeric entry, mobile editing, save/list refresh, conflict retention and accessibility. The mobile editor keeps its heading and save/cancel actions visible while the fields scroll. Browser fixtures never change actual prices.
