# ADR-011 — رفرنس‌ها و منشأ محتوای آموزشی

وضعیت: جهت پیشنهادی برای طراحی محتوا؛ فهرست دانشگاه‌ها و استاندارد انتشار هنوز باز است.  
تاریخ: 2026-10-18

## زمینه

هدف آموزشی، ساخت کاتالوگی کامل از مباحث مدیریت با بررسی برنامه‌های MBA/DBA، کتاب‌ها، مقالات علمی، جزوه‌ها و منابع عمومیِ قابل‌دسترسی است. کاربر باید بداند هر درس بر پایهٔ چه منابعی تدوین شده است.

## جهت پیشنهادی

- منابع بر اساس کاتالوگ MBA، درس، گرایش و نوع منبع دسته‌بندی شوند.
- برای هر منبع، عنوان، نویسنده/استاد، دانشگاه یا ناشر، سال، پیوند و وضعیت دسترسی ثبت شود.
- در صفحهٔ آموزش، منابع به‌کاررفته و سال مرجع تحقیق (برای نمونه ۲۰۲۶) قابل‌مشاهده باشند.
- نام دانشگاه فقط منشأ یک منبع یا برنامهٔ بررسی‌شده را نشان دهد؛ متن محصول نباید به‌اشتباه تأیید، همکاری یا مدرک رسمی آن دانشگاه را القا کند.
- هاروارد و استنفورد جزو دانشگاه‌های موردنظر کاربر برای بررسی‌اند؛ مجموعهٔ نهایی دانشگاه‌ها هنوز انتخاب نشده است.

## کارهای باز

روش انتخاب منابع برتر، حداقل شواهد لازم برای هر درس، سطح دسترسی و مجازبودن بازنشر، شیوهٔ خلاصه‌سازی و بازبینی علمی باید پیش از تولید انبوه محتوا تعیین شوند.
