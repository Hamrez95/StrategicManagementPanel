# ADR-004 — Journey and input dependencies

Status: accepted for development, 2026-10-15.

Context: startup research supports six phases with re-entry; organization graph is only partly adaptive. Completion and transition conditions are prose.

Decision: promote small typed reviewed step contracts. Validate prerequisite DAG separately from legal stage return transitions. JourneyRun pins release/input scope; completion needs a relevant reviewed output, not a filled-field percentage. Canonical data and verified import/derivation precede questions. Skip/defer preserve unknown and block only dependent commitments.

Consequence: guided/expert share engine output and global education preferences. No hard-coded page wizard or general external workflow engine. STR-059–061/064 own first slice; STR-066 handles organization IDs/relevance gates before broader promotion.
